## 📝 Problem Statement

You are given an integer array **nums** of size **N** .

Your task is to print all the elements of the array in the same order as they appear, separated by spaces.

### Example 1:

**Input:**

```
nums = [10, 20, 30, 40, 50]
```

**Output:**

```
10 20 30 40 50
```

### Example 2:

Input:

```
nums = [-5, 0, 15, -10]
```

Output:

```
-5 0 15 -10
```

Still unsure what the problem is asking ?

Let’s go through a few more examples, step by step, to make it clearer.

### Constraints

- 1 <= N <= 100
- -10^5 <= nums[i] <= 10^5

## 💡 Complexity Analysis

- **Time Complexity:** $\mathcal{O}(N)$
- **Space Complexity:** $\mathcal{O}(1)$
