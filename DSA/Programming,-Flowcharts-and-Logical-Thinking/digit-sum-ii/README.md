## 📝 Problem Statement

You are given a non-negative integer N.

Find and print the sum of all digits present in N.

### Example 1:

**Input:**

```
N = 2917
```

**Output:**

```
19
```

**Explanation:**

The sum of digits of given number 2917 is => 2 +9 +1 +7 => 19.

### Example 2:

**Input:**

```
N = 100
```

**Output:**

```
1
```

**Explanation:**

The sum of digits of given number 100 is => 1 + 0 + 0 => 1.
