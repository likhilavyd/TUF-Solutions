## 📝 Problem Statement

You are given an integer array nums and an integer target. Using recursion, return the number of times target occurs in nums.

**Note:**

A normal iterative solution will pass the test cases, but the goal of this problem is to solve it using recursion and strengthen your understanding of recursive calls and base cases.

### Example 1:

**Input:** nums = [1, 2, 2, 3, 2], target = 2

**Output:** 3

**Explanation:** The target 2 appears three times in nums.

### Example 2:

**Input:** nums = [4, 5, 6, 7], target = 3

**Output:** 0

**Explanation:** The target 3 does not occur in nums.
