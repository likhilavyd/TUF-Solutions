## 📝 Problem Statement

You are given a 2D integer matrix with N rows and M columns. Your task is to print all the elements of the matrix in the same order as they appear.

Print each row on a separate line, with elements separated by a single space.

### Example 1:

**Input:**

```
Matrix = [
    [1, 2, 3],
    [4, 5, 6]
]
```

**Output:**

```
1 2 3
4 5 6
```

### Example 2:

**Input:**

```
Matrix = [
    [-10, 10],
    [2, 3]
]
```

**Output:**

```
-10 10
2 3
```

### Constraints

- 1 <= N, M <= 100
- -10^5 <= matrix[i][j] <= 10^5

## 💡 Complexity Analysis

- **Time Complexity:** $\mathcal{O}(N)$
- **Space Complexity:** $\mathcal{O}(1)$
