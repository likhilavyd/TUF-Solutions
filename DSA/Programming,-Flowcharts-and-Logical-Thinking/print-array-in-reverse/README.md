## 📝 Problem Statement

Given an integer array nums, print all its elements in reverse order using recursion.

Print consecutive elements separated by a single space. Do not print a trailing space after the final element. Print a newline character after the complete reversed array.

**Note:**

A normal iterative solution will pass the test cases, but the goal of this problem is to solve it using recursion and strengthen your understanding of recursive calls and base cases.

### Example 1:

**Input:** nums = [10, 20, 30, 40, 50]

**Output:** 50 40 30 20 10

**Explanation:** Starting from the final element, the array is printed recursively toward the first element.

### Example 2:

**Input:** nums = [-5, 0, 15, -10]

**Output:** -10 15 0 -5

**Explanation:** Every element is printed in the opposite order from its position in nums.
