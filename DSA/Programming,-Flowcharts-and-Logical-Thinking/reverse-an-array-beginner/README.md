## 📝 Problem Statement

You are given an array arr containing N integers.

Reverse the order of the elements in arr and print the reversed array.

**Input**

The input contains:

- An integer N — the number of elements in the array arr.
- N integers — the elements of arr.

**Output**

- Print the elements of arr in reverse order, separated by spaces.

### Example 1:

<strong style="color:rgb(243, 244, 246)">Input</strong>:

```
5
1 2 3 4 5
```

Output:

```
5 4 3 2 1
```

**Explanation:**

The reverse of the array [1,2,3,4,5] is [5,4,3,2,1]

### Example 2:

<strong style="color:rgb(243, 244, 246)">Input:</strong>

```
4
10 20 30 40
```

**Output:**

```
40 30 20 10
```

**Explanation:**

The reverse of the array [10,20,30,40] is [40,30,20,10].
