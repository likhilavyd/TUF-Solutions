## 📝 Problem Statement

You are given an integer **day** . Print the corresponding day of the week.

The week starts with Monday as day 1 and ends with Sunday as day 7.

**Input**

- The input contains one integer day.

**Output**

Print the day of the week corresponding to day, without labels or trailing spaces.

### Example 1:

**Input:**

```
1
```

**Output:**

```
Monday
```

**Explanation:**

Day 1 corresponds to Monday.

### Example 2:

**Input:**

```
7
```

**Output:**

```
Sunday
```

**Explanation:**

Day 7 corresponds to Sunday.

- 1 <= day <= 7
