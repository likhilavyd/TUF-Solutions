## 📝 Problem Statement

You are given an integer **N** . Determine whether the integer is positive, negative, or zero.

**Input**

- The input contains one integer N.

**Output**

Print **Positive** if N is greater than zero, **Negative** if N is less than zero, or **Zero** if N equals zero. Print the result without labels or trailing spaces.

### Example 1:

**Input:**

```
7
```

**Output:**

```
Positive
```

**Explanation:**

7 is greater than zero, so it is positive.

### Example 2:

**Input:**

```
-4
```

**Output:**

```
Negative
```

**Explanation:**

-4 is less than zero, so it is negative.
