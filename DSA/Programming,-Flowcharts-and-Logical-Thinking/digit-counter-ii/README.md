## 📝 Problem Statement

You are given a non-negative integer N for each test case. Find and print the number of digits present in N.

The number 0 contains one digit.

### Example 1:

**Input:**

```
N = 12345
```

**Output:**

```
5
```

**Explanation:**

12345 contains five digits.

### Example 2:

**Input:**

```
0
```

**Output:**

```
1
```

**Explanation:**

0 is treated as a one-digit number.

### Constraints

- 0 <= N <= 10^9
