## 📝 Problem Statement

You are given two integers **A** and **B** . Determine and print the larger integer. If both integers are equal, print **Equal** .

**Input**

- The input contains two space-separated integers A and B.

**Output**

Print the larger integer. If both integers are equal, print **Equal** . Print the result without labels or trailing spaces.

### Example 1:

**Input:**

```
10 100
```

**Output:**

```
100
```

**Explanation:**

100 is larger than 10.

### Example 2:

**Input:**

```
8 8
```

**Output:**

```
Equal
```

**Explanation:**

Both integers have the same value, so the result is Equal.
