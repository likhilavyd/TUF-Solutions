## 📝 Problem Statement

You are given two integers **A** and **B** . Swap their values and print the numbers after swapping.

**Input**

The input contains two space-separated integers A and B.

**Output**

Print two integers separated by a single space: the value of B followed by the value of A. Print the result without labels or trailing spaces.

### Example 1:

**Input:**

```
5 3
```

**Output:**

```
3 5
```

**Explanation:**

After swapping 5 and 3, the values become 3 and 5.

### Example 2:

**Input:**

```
10 20
```

**Output:**

```
20 10
```

**Explanation:**

After swapping 10 and 20, the values become 20 and 10.
