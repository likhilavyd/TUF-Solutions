## 📝 Problem Statement

You are given an integer array **nums** and an integer **target** . Using recursion, return the smallest zero-based index at which **target** occurs in **nums** . If **target** is not present, return **-1** .

**Note:**

A normal iterative solution will pass the test cases, but the goal of this problem is to solve it using recursion and strengthen your understanding of recursive calls and base cases.

### Example 1:

**Input:** nums = [2, 3, 4, 5, 3], target = 3

**Output:** 1

**Explanation:** The first occurrence of 3 is at index 1.

### Example 2:

**Input:** nums = [2, -4, 4, 0, 10], target = 6

**Output:** -1

**Explanation:** The target 6 does not occur in nums.
