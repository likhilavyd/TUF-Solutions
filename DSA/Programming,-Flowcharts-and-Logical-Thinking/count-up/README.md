## 📝 Problem Statement

You are given an integer **N** for each test case. Print all integers from 1 to N in increasing order.

**Input**

- The input contains one integer N.

**Output**

Print the integers from 1 to N in increasing order, separated by a single space, without labels or trailing spaces.

### Example 1:

**Input:**

```
5
```

**Output:**

```
1 2 3 4 5
```

**Explanation:**

For N = 5, print the numbers from 1 through 5.

### Example 2:

**Input:**

```
1
```

**Output:**

```
1
```

**Explanation:**

For N = 1, only 1 is printed.
