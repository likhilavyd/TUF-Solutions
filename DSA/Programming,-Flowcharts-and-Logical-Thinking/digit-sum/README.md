## 📝 Problem Statement

You are given a non-negative integer **N** for each test case. Find the sum of all its digits.

**Input**

- The input contains an integer N.

**Output**

Print the sum of all digits of N, without labels or trailing spaces.

### Example 1:

**Input:**

```
123
```

**Output:**

```
6
```

**Explanation:**

1 + 2 + 3 = 6.

### Example 2:

**Input:**

```
0
```

**Output:**

```
0
```

**Explanation:**

The digit sum of 0 is 0.
