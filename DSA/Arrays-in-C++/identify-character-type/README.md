## 📝 Problem Statement

You are given a single character **ch** . Determine whether the character is an uppercase English letter, a lowercase English letter, a digit, or a special character.

Return the corresponding character type according to these rules:

- "Uppercase" if ch is an uppercase English letter (A–Z).
- "Lowercase" if ch is a lowercase English letter (a–z).
- "Digit" if ch is a digit (0–9).
- "Special Character" for any other printable ASCII character.

### Example 1:

**Input:**

```
ch = 'A'
```

**Output:**

```
Uppercase
```

**Explanation:**

A is an uppercase English letter, so the output is Uppercase.

### Example 2:

**Input:**

```
ch = '7'
```

**Output:**

```
Digit
```

**Explanation:**

7 is a numeric digit, so the output is Digit.
