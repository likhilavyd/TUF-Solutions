## 📝 Problem Statement

You are given a list nums consisting of N integers. Your task is to read the list and print all its elements in the same order, separated by spaces.

### Example 1:

**Input:**

```
nums = [10, 20, 30, 40, 50]
```

**Output:**

```
10 20 30 40 50
```

**Explanation:**

The given list contains five elements: 10, 20, 30, 40, 50.

Print all the elements in their original order, separated by spaces. Since no modification is required, the output is 10 20 30 40 50.

### Example 2:

**Input:**

```
nums = [-1, 0, 5, 8]
```

**Output:**

```
-1 0 5 8
```

**Explanation:**

The given list contains four elements: -1, 0, 5, 8.

Print each element in its original order, including the negative number -1 and zero. The output is -1 0 5 8.
