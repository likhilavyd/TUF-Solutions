## 📝 Problem Statement

Given a year year and a month month, return the number of days in that month.

### Example 1:

**Input:** year = 2024, month = 1

**Output:** 31

### Example 2:

**Input:** year = 2023, month = 2

**Output:** 28

### Constraints

- 1583 <= year <= 2100
- 1 <= month <= 12
