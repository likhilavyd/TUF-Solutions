## 📝 Problem Statement

Given a number n, check whether a given number is even or odd.

Return "even" if Even else "odd".

### Example 1:

**Input:** n=5

**Output:** odd

**Explanation:** 5 is not divisible by 2.

### Example 2:

**Input:** n=4

**Output:** even

**Explanation:** 4 is divisible by 2.
