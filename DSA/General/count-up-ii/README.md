## 📝 Problem Statement

You are given an integer N. Using recursion, print all integers from 1 to N in increasing order .

Print consecutive integers separated by a single space. Do not print a trailing space after N. Print a newline character after the complete sequence.

**Note:**

A normal iterative solution will pass the test cases, but the goal of this problem is to solve it using recursion and strengthen your understanding of recursive calls and base cases.

### Example 1:

**Input:** N = 5

**Output:** 1 2 3 4 5

**Explanation:** Starting from 1, recursively include each integer until 5 is reached.

### Example 2:

**Input:** N = 1

**Output:** 1

**Explanation:** Since N is 1, the sequence contains only 1.
