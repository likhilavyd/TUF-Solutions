## 📝 Problem Statement

Given an integer n, return true if and only if it is an Armstrong number.

The k-digit number n is an Armstrong number if and only if the k^th power of each digit sums to n.

### Example 1:

**Input:** n = 9474

**Output:** true

**Explanation:** 9474 is a 4-digit number, and 9474 = 9^4 + 4^4 + 7^4 + 4^4 = 9474.

### Example 2:

**Input:** n = 9475

**Output:** false

**Explanation:** 9475 is a 4-digit number, but 9475 != 9^4 + 4^4 + 7^4 + 5^4 = 9843.
