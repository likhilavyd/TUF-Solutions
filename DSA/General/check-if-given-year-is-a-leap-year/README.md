## 📝 Problem Statement

Given an integer year, determine whether it is a leap year. Return **"Yes"** if it is a leap year, otherwise return **"No".**

### Example 1:

**Input:** 1996

**Output:** Yes

**Explanation:** 1996 is divisible by 4 and not by 100, so it's a leap year.

### Example 2:

**Input:** 2000

**Output:** Yes

**Explanation:** 2000 is divisible by 400, so it's a leap year.
