## 📝 Problem Statement

Given an integer **n** , determine whether it is **Positive** , **Negative** , or **Zero** .

Return the string:

- **"Positive"** if **n > 0**
- **"Negative"** if **n < 0**
- **"Zero"** if **n == 0**

### Example 1:

**Input:** n = 5

**Output:** "Positive"

### Example 2:

**Input:** n = -5

**Output:** "Negative"
