## 📝 Problem Statement

Given an integer array nums, return 0 if the sum of the digits of the minimum integer in nums is odd, or 1 otherwise.

### Example 1:

**Input:** nums = [42, 17, 3, 56, 29, 11]

**Output:** 0

**Explanation:** The minimal element is 3, and the sum of its digits is 3, which is odd. Thus, the answer is 0.

### Example 2:

**Input:** nums = [88, 21, 14, 35, 62]

**Output:** 0

**Explanation:** The minimal element is 14, and the sum of its digits is 1 + 4 = 5, which is odd. Thus, the answer is 0.
