## 📝 Problem Statement

Given a non-negative integer N, return the sum of all digits present in N using recursion.

**Note:**

A normal iterative solution will pass the test cases, but the goal of this problem is to solve it using recursion and strengthen your understanding of recursive calls and base cases.

### Example 1:

**Input:** N = 2917

**Output:** 19

**Explanation:** The sum of the digits is 2 + 9 + 1 + 7 = 19.

### Example 2:

**Input:** N = 100

**Output:** 1

**Explanation:** The sum of the digits is 1 + 0 + 0 = 1.
