## 📝 Problem Statement

You are given a single English alphabet character **ch** .

Determine whether the character is a vowel, ignoring case. The vowels are A, E, I, O, and U in uppercase or lowercase.

Return **true** if the character is a vowel; otherwise, return **false** .

### Example 1:

**Input:**

```
ch = 'A'
```

**Output:**

```
true
```

**Explanation:**

A is an uppercase vowel, so the output is true.

### Example 2:

**Input:**

```
ch = 'b'
```

**Output:**

```
false
```

**Explanation:**

b is a consonant, so the output is false.
