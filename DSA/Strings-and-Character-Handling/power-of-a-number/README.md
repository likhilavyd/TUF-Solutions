## 📝 Problem Statement

Given two integers base and exponent, return base raised to the power exponent using recursion.

When exponent is 0, the result is 1.

**Note:**

A normal iterative or built-in power solution will pass the test cases, but the goal of this problem is to solve it using recursion and strengthen your understanding of recursive calls and base cases.

### Example 1:

**Input:** base = 2, exponent = 5

**Output:** 32

**Explanation:** 2^5 = 2 * 2 * 2 * 2 * 2 = 32.

### Example 2:

**Input:** base = 7, exponent = 0

**Output:** 1

**Explanation:** Any nonzero number raised to the power 0 is 1.
