## 📝 Problem Statement

You are given an integer N representing a single digit from 0 to 9.

Your task is to convert this integer into its corresponding digit character and return the character.

### Example 1:

**Input:**

```
N = 7
```

**Output:**

```
'7'
```

**Explanation:**

The given integer is 7. Adding the character '0' to the digit value converts it into the corresponding digit character '7'.

### Example 2:

**Input:**

```
N = 0
```

**Output:**

```
'0'
```

**Explanation:**

The given integer is 0. Its corresponding digit character is '0'.
