## 📝 Problem Statement

Given a string **s** , convert each lowercase English letter to uppercase and each uppercase English letter to lowercase. Leave all other characters unchanged. Return the resulting string.

### Example 1:

**Input:** s = "Hello World"

**Output:** "hELLO wORLD"

**Explanation:** Letters switch case; the space is unchanged.

### Example 2:

**Input:** s = "aBc123"

**Output:** "AbC123"

**Explanation:** Digits remain unchanged.

### Constraints

- 1 <= s.length() <= 100000
- Sum of lengths of all strings in one test file <= 100000
- s contains printable ASCII characters, including spaces.
